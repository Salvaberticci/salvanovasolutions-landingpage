# SalvaNova Solutions - Landing Page

¡Bienvenido al repositorio de la landing page de SalvaNova Solutions! Este proyecto es una página de aterrizaje moderna y responsiva diseñada para presentar los servicios y la visión de SalvaNova Solutions.

## Descripción del Proyecto

Esta landing page está construida con tecnologías web estándar (HTML, CSS, JavaScript) y se enfoca en proporcionar una experiencia de usuario fluida y atractiva. Su objetivo principal es captar la atención de visitantes, informar sobre los servicios ofrecidos y facilitar el contacto con SalvaNova Solutions.

## Características

*   **Diseño Responsivo:** Adaptable a diferentes tamaños de pantalla (escritorio, tabletas, móviles).
*   **Navegación Intuitiva:** Menú de navegación fácil de usar para acceder a las diferentes secciones.
*   **Secciones Claras:** Información organizada en secciones como "Inicio", "Servicios", "Acerca de nosotros", "Portafolio" y "Contacto".
*   **Formulario de Contacto:** Un formulario sencillo para que los usuarios puedan enviar consultas directamente.
*   **Animaciones y Transiciones:** Elementos visuales dinámicos para mejorar la experiencia del usuario.
*   **Optimización SEO:** Estructura básica para una buena indexación en motores de búsqueda.

## Tecnologías Utilizadas

*   **HTML5:** Para la estructura y contenido de la página.
*   **CSS3:** Para el diseño y estilo visual.
*   **JavaScript (ES6+):** Para la interactividad y funcionalidades dinámicas.

## Cómo Ejecutar el Proyecto Localmente

Para tener una copia local del proyecto funcionando, sigue estos sencillos pasos:

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/Salvaberticci/salvanovasolutions-landingpage.git
    ```
2.  **Navegar al directorio del proyecto:**
    ```bash
    cd salvanovasolutions-landingpage
    ```
3.  **Abrir `index.html`:**
    Simplemente abre el archivo `index.html` en tu navegador web preferido. No se requiere un servidor web para la funcionalidad básica, aunque puedes usar uno si lo deseas (por ejemplo, con Live Server de VS Code).

## Estructura de Archivos

El proyecto sigue una estructura de archivos clara y organizada:

```
.
├── anexo-proteccion-datos.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── images/
│   │   ├── foto-mia.png
│   │   └── logos/
│   │       ├── logo-2.png
│   │       └── logo.png
│   └── js/
│       └── main.js
├── descargo-de-responsabilidad.html
├── index.html
├── info.txt
├── politica-de-privacidad.html
├── proteccion-de-datos.html
├── README.md
└── terminos-y-condiciones.html
```

*   `index.html`: El archivo principal de la landing page.
*   `assets/`: Contiene todos los recursos estáticos del proyecto.
    *   `css/style.css`: Hoja de estilos principal.
    *   `images/`: Imágenes utilizadas en la página.
    *   `js/main.js`: Archivo JavaScript para la interactividad.
*   `anexo-proteccion-datos.html`, `descargo-de-responsabilidad.html`, `politica-de-privacidad.html`, `proteccion-de-datos.html`, `terminos-y-condiciones.html`: Páginas adicionales para información legal y de privacidad.
*   `info.txt`: Archivo de texto con información adicional (posiblemente de configuración o notas).
